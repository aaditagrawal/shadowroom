Shadowroom v0.1.6 ships the Import and quit-shortcut changes intended for v0.1.5, whose release pipeline stopped before publication.

The CPU/X11 prototype lockfile now tracks the current app version. A release preflight checks both lockfiles before compiling, with regression coverage for stale versions. Core tests and native packaging run concurrently after preflight; publication still requires all core and native jobs. A release tag promotes successful mainline artifacts of the exact same commit, with checksummed build provenance and a fresh-build fallback. Documentation-only branch/PR edits skip native jobs. The CPU/X11 check shares the core Cargo target/cache; Fedora dependency caches survive version bumps; cache writes are limited to main; artifact retention is shorter; lightweight jobs use single-CPU runners; compilers use the standard runner CPUs.

- The Import column is grouped into Destination, Naming, Options and More instead of one long list of text buttons. Options use explicit controls: Videos Include/Skip and name collisions Add suffix/Skip.
- Preset and Import selection are real dropdowns. They open below their field above the panel, mark the current choice and list each preset's templates. Up/Down, Enter and Escape navigate them; clicking outside closes them. The preset label shows Custom once a template is edited, and the same menu saves the current templates as a preset.
- A naming token reference sits under the templates. Hover a token for its meaning, or click it to insert it at the caret of the subfolder or filename template. The Example path now appears directly below the templates. A test keeps the reference in step with the template parser.
- Rated imports show a five-star minimum-rating control. Close panel moved to the existing close button in the Import footer.
- Ctrl+Q (Cmd+Q on macOS) quits from every view, including while the Import panel, Preferences, a menu, a dialog or a text field has focus. It still waits for pending decision writes, exports and imports.
- Error messages wrap within the notification instead of running past the window edge and hiding its dismiss button.

The portable Linux AppImage/archive remains x86_64 with glibc 2.28 or newer and requires a compatible desktop session and Vulkan driver. macOS archives remain arm64, signed ad hoc and not notarized. Fedora 44 RPMs use system libraries/codecs.

After the [COPR build](https://copr.fedorainfracloud.org/coprs/aaditagrawal/shadowroom/) succeeds for Fedora 44 x86_64, existing COPR installs update with:

```sh
sudo dnf upgrade --refresh shadowroom
```
