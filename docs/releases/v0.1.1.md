Shadowroom v0.1.1 improves the ingest and culling workflow from Rithwik's feedback and adds automated native releases.

- Inspect detail using the paired or embedded JPEG before developing sensor RAW. Zoom ranges from 12.5% to 800%, preserves zoom and pan between frames, and loads adjacent previews ahead of time. Automatic memory sizing adapts to the computer.
- Compare only the photos selected in Catalog. Return to Catalog to recover that selection, or choose Show full folder to leave the subset.
- Toggle cyan focus peaking with F in Review and both Compare panes.
- Use anchored Shift+Arrow selection, draggable scrollbars, partial time-group selection indicators, and visible blinking text carets.
- Preferences use explicit Apply/Cancel. Getting Started explains the workflow, keyboard shortcuts, time grouping, labels, and caching; reopen it with F1.
- R or Reset clears stars and pick/reject together, retains color labels, and never auto-advances. Undo restores the reset as one action. Repeated rating, Pick, and Reject keys continue to set their decision.
- CI uses generated test fixtures, checks Linux and macOS, and packages verified release inputs with dependency notices and checksums. Releases are built from version tags.

Zoom preservation already worked before this release; the changes address inspection speed and zoom control. The Gap question was answered and is now explained in the interface.

Choose the asset for your platform. Linux AppImages target x86_64 with glibc 2.28 or newer and bundle the documented RAW/HEIF codecs. A compatible desktop session and Vulkan driver remain required. macOS archives are arm64, signed ad hoc, and not notarized; HEIF uses system frameworks, and sensor RAW fallback requires a compatible LibRaw installation. Display output remains 8-bit sRGB.

The Fedora 44 x86_64 RPM installs with `sudo dnf install ./shadowroom-0.1.1-1.fc44.x86_64.rpm`. It uses Fedora's system libraries and optional system codecs, and includes a corresponding source RPM for offline rebuilding. Installing this file does not configure automatic updates. A Shadowroom COPR repository is separate setup; see `docs/FEDORA.md`.

Each downloadable archive or executable has a matching SHA-256 checksum. See the build, format-support, and Fedora packaging guides in the source tree for prerequisites and installation details.
