Shadowroom v0.1.7 updates photo review, card imports and desktop navigation.

- Queue a second card while the first imports, remove waiting cards, and retry failed photos from Import or History. Imports can resume when a card with a filesystem UUID returns at a different mount point.
- Review photos with focus peaking and clipping overlays, pointer-centered zoom, and synchronized Compare controls. Theme and text-size settings apply across the review and import views.
- Export picks from the current view or use the palette to export picks from the whole catalog. The folder chooser remembers the last export destination.
- Fedora COPR now targets Fedora 44 and 45 on x86_64, plus Fedora 43 while COPR accepts new builds for it. Once the build succeeds for your Fedora version, enable the repository with `sudo dnf copr enable aaditagrawal/shadowroom` and install with `sudo dnf install shadowroom`. Existing installations update with `sudo dnf upgrade --refresh shadowroom`.

The GitHub release includes the Fedora 44 RPM and vendored source RPM. The portable Linux AppImage and archive target x86_64 with glibc 2.28 or newer and require a compatible desktop session and Vulkan driver. The macOS arm64 archive is signed ad hoc and has no notarization.
